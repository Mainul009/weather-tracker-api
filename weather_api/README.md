# Weather Tracker API

This is a simple weather tracking API that provides weather data based on user input.

## Features
- Get current weather data
- Forecast for the next 7 days

## Installation
1. Clone the repository
2. Install dependencies using `npm install`
3. Run the application using `npm start`

## Usage
- Endpoint: `/weather`
- Method: `GET`
- Query Parameters: `location` (e.g., `?location=London`)
